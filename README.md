# Күү Мурас

Комузду онлайн үйрөнүү платформасы. **React 18 + Vite + React Router 6 + CSS Modules.**
Үч окуу жолу: **Видео**, **Ноталар**, **Санарип комуз**.

## 1. Иштетүү

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production → dist/
npm run preview    # build'ди текшерүү
```

Node.js 18+ керек.

## 2. Vercel'ге жүктөө (GitHub аркылуу)

1. GitHub'та жаңы репозиторий ачып, бул папканы жүктө (`node_modules` жана `dist` жүктөлбөйт, `.gitignore` бар).
2. vercel.com → **Add New → Project** → репозиторийди танда.
3. Framework: **Vite** (өзү аныкталат). Build: `npm run build`, Output: `dist`.
4. **Deploy**. Барактарды жаңыртканда 404 чыкпашы үчүн `vercel.json` даяр (rewrite). Netlify үчүн `public/_redirects` бар.

## 4. Видео жана ноталарды кошуу (эң маанилүү)

Файлдарды `public/media/` ичине сал да, **`src/data/media.js`** файлында жолун жаз:

```js
export const MEDIA = {
  'komuz-emne': {                                   // ← сабактын slug'ы
    video: {
      file: '/media/videos/komuz-emne.mp4',         // өз видеоң (милдеттүү эмес)
      poster: '/media/videos/komuz-emne.jpg',       // мукабасы (милдеттүү эмес)
      youtube: 'dQw4w9WgXcQ',                       // YouTube коду (милдеттүү эмес)
    },
    notation: [
      { title: 'Ноталар', src: '/media/notes/komuz-emne.pdf' },   // PDF, SVG, PNG же JPG
    ],
  },
};
```

- Экөө тең (file + youtube) болсо, сайт «Түз видео / YouTube» которгучун көрсөтөт.
- Ылдамдык: түз видеодо 0.25×–2× (слайдер + даяр баскычтар), YouTube'до YouTube колдогон ылдамдыктар. Үндүн бийиктиги өзгөрбөйт (`preservesPitch`).
- Slug'дар: `src/data/lessons.js` (16 сабак) жана `src/data/kuu.js` (күүлөр).

## 5. Санарип комуздун ырааттуулугу (tab)

`lessons.js` / `kuu.js` ичинде ар бир сабактын `tab` талаасы бар:

```js
tab: [n(1, 0, 1, 0), n(1, 2, 1, 1), n(1, 4, 1, 2)]   // n(кыл, позиция, узундук, манжа)
```

- кыл: 0 = I, 1 = II (ортоңку), 2 = III
- позиция: ачык кылдан жарым тон менен (0 = ачык, 2 = эки жарым тон жогору)
- узундук: согуу саны (1 = бир, 0.5 = жарым)
- манжа: 0 = ачык, 1–4 = сол колдун манжалары

Толтурсаң: санарип комуз күүнү ойнотот, «Ноталар» бөлүмүндө нота аттары (Ля = A) автоматтык чыгат.
`kerbez-1`, `kerbez-2`, `atkaruu` жана бардык күүлөрдүн `tab` талаасы **бош** — чыныгы нотаны өзүң жаз.

Күүлөө (`src/data/tunings.js`): Ре–Ля–Ре (квинта) жана Ре–Соль–Ре (кварта) үлгү катары коюлган. Мугалимиңдин күүлөөсүнө жараша `midi` сандарын өзгөрт (62 = Ре, 67 = Соль, 69 = Ля).

## 7. Бар функциялар

- Сол меню жана оң панель ачылат/жабылат (мобилдикте чекмеле), абалы эсте сакталат
- 5 түс палитрасы × караңгы/жарык/авто режим
- «Жогору чыгуу» баскычы, барак алмашканда жогорудан башталат
- Издөө (сабак жана күү), тандалгандар (♥), аткарылган сабактар
- **«Улантуу» / «Эң акыркы кайда калдың»** — акыркы ачылган сабак же күү (оң панелде, башкы бетте, «Менин жолум» баракчасында)
- Метроном, Комуз күнү эсептегичи (9-сентябрь), күүлөгүч (кылдардын үнү + микрофон)
- Кирүү/Катталуу — азырынча үлгү барак (сервер жок)

## 8. Текшерүү керек болгон нерселер

- **Мазмундун тактыгы:** комуз жөнүндө тексттер ачык булактардан (Википедия, Kaktus.media) өз сөз менен жазылды. Күүлөрдүн авторлору (`kuu.js`) жана аткаруучулар тууралуу маалыматты мугалимиң менен текшер. Белгисиз жерлер `// TODO` менен белгиленген.
- **Сүрөттөрдүн укугу:** `src/data/images.js` ичинде булактарды толтур. Музейдин сүрөтү (Гапар Айтиев) жана почта маркасы үчүн булагын көрсөтүү сакталган. Башка сүрөттөрдүн автору белгисиз — жарыялаардан мурун текшер.
- **Шрифттер:** Google Fonts'тан жүктөлөт (интернет керек).
